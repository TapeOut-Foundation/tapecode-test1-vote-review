## 这次分析是怎么做的

### 1. 读公示表，核对数字
公示表有三套口径：

| 口径 | 含义 |
|---|---|
| 原始票 | 数据库内全部有效提交，含快照持有人和普通 1 票地址 |
| 快照票 | 活动前资产快照内的地址（BEM ≥ 1、持 Test1 NFT、官方矿机、NAND/LATCH），每个合格地址 3 票 |
| 历史严格票 | 快照票 ∩ 首轮前冻结的 67 人固定名单（按 X 动态审核得出） |

三个赛段的汇总表和逐笔明细交叉核对，两者一致。决赛：003 严格 56 票（20 人），056 严格 45 票（15 人）。

### 2. 找出“未进入名单的账号”
决赛里是快照持有人、但不在 67 人名单里的账号：**056 方 40 个（120 票）、003 方 13 个（39 票）**。这些账号的票只算进“快照票”，不算进“严格票”，是争议所在。

### 3. 用投票轨迹结构分组（只用数据，不看内容）
把每个账号在三轮的投票对象串起来：

| 组 | 人数 | 特征 |
|---|---|---|
| 056·A | 19 | 56 进 3 投 033，033 被淘汰后，之后两轮全部转投 056 |
| 056·B | 14 | 第 2 或第 3 轮才第一次出现 |
| 056·C | 4 | 第 1 轮起一直投 056 |
| 056·D | 3 | 第 1 轮投别的作品，后转 056 |
| 003·E / F / G | 7 / 4 / 2 | 一直投 003 / 中途转投 003 / 后来才出现 |

**关键发现**：67 人固定名单恰好等于第一轮的严格有效投票人——名单只来自第一轮投票的人，**后来才出现的账号没有被审核的机会**（056 方 14 个、003 方 2 个）。

### 4. 三种口径的边界

| 口径 | 003 | 056 |
|---|---|---|
| A 官方严格票 | 56 | 45 |
| B 严格 + 全部快照持有人（无审核） | 95 | 165 |
| C 快照 − 033 转投账号 19 人 | 95 | 108 |
| **D 复核后** | **71** | **78** |

### 5. 逐个到 X 上核查（只读）
标准由基金会给定：

**合格**（满足任一，且需实质性互动或原创）：
1. 与 @TapeOutWorld、@FirstoAI、@Blonskr、@TapeOutCF 真实回复、评论或带字引用；
2. 原创发布含 TapeOut、TapeCode、Test1、BEM、NAND、LATCH、矿机、流片 等关键词；
3. 与已知 Builder / Core Supporter 真实互动；
4. 有明确捐赠或开发 TapeOut 相关工具 / 游戏的记录。

**排除**：仅点赞 / 纯转发 / 关注；仅单词提及（如单独“BEM!”）；跨项目任务型、批量行为；讨论其他项目与 TapeOut 无关；内容空泛内容。间接讨论可计入，但要判断是不是真正参与社区讨论。

做法：在基金会成员已登录的 Chrome 里，用脚本滚动每个账号的**主页**和 **/with_replies** 页，提取自发帖、回复对象和转帖，按标准判断，每个结论附推文链接（[`scripts/x_timeline_scan.js`](scripts/x_timeline_scan.js)）。过程中并行派了几个 agent 分批核查，由我汇总。**全程只读**：没有点赞、转发、关注、发帖或回复。

### 6. 标准与方法的调整记录

| 阶段 | 调整 |
|---|---|
| 标准对齐 | 单词提及不算；间接讨论可计入，但要判断是否真参与社区；需实质性互动或原创 |
| 纠正一个错误 | 第一轮只扫了回复页，漏掉原创帖，@EasonOnly 被误判。重扫主页后发现他 46 条自发帖里 18 条含 TapeOut/BEM，并写明“我捐赠两张 NFT”，改判为明确计入；此后对未通过的账号都用“主页 + 回复页”重扫 |
| 转推 | 基金会成员指出 @EasonOnly 有转推 TapeOut 内容（他已计入，不影响结果）；脚本对所有账号的转推数都是 0，识别未校准 |
| 成员确认边缘账号 | 计入：@nctptd（社区成员）、@dngl829114、@fngqiojng11044、@KyymYu、@unrealhb、@madola0429。不计入：@tapeagentai、@tapewallet、@LewickiDamian、@0xsenlin（抽奖类账号）、@tapecodenft、@tapeoutnft、@simplede22、@steawen5211 |

### 7. 判定与重算

| | 合格 | 不计入 | 存疑 | 合计 |
|---|---|---|---|---|
| 056 方 | 11 | 27 | 2 | 40 |
| 003 方 | 5 | 6 | 2 | 13 |

“存疑”是账号不存在 / 已冻结，没有内容可核，不计票。**033 转投账号 19 人里 0 人合格**：其中 16 人的公开内容是回复其他项目（@cashmerelabs、@perlelabs 等）的相近内容的回复，1 人是抽奖类账号，2 人无内容。

- 003 = 56 + 5×3 = **71**
- 056 = 45 + 11×3 = **78**

### 8. 敏感性
056 方被剔除 k 个合格账号、003 方多被认可 m 个，056 仍领先当且仅当 78 − 3k > 71 + 3m：m = 0 时 k ≤ 2 仍领先，k = 3 反超。被判不计入的 @simplede22、@steawen5211（均投 003，共 6 票）即使改计入，003 为 77，仍落后 1 票。

![翻盘边界](chart2_pivot_grid.png)

### 9. 措辞原则
投票模式（如“19 人整体转投”）既可能是有组织，也可能是支持者的第二选择，数据分不出来，所以**不对任何账号作“有组织行为”的判断**，结论只建立在 X 内容证据上。

## 局限
- 脚本主要看每个账号主页和回复页的近期内容（约 6–14 屏），更早的内容可能没逐条看。
- **转推识别未经校准**：脚本对所有账号转推数都是 0，但已知 @EasonOnly 有转推 TapeOut 内容；转推不改变本次结果，但其他账号的转推没有被系统核查。
- 4 个存疑账号（不存在 / 已冻结）无内容可查；账号后来改名或注销的，当时是否合格无法回溯。
- @madola0429 的一条原创讲解帖完整链接未补；@fernanseers8824 的捐赠记录、@madola0429 的麻将游戏开发记录未独立核实。
- 公示表没有时间戳和钱包信息，无法分析提交时间或资金关联。
