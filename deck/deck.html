Review criteria

审核标准：真实的生态内容与互动有效，空泛与批量无效

有效（需实质性互动或原创）

  • ① 与 @Blonskr、@TapeOutCF 等生态账号真实回复、评论或带字引用
  • ② 原创含 TapeOut、TapeCode、Test1、BEM、NAND、LATCH、矿机、流片 等内容
  • ③ 与已知 Builder / Core Supporter 真实互动
  • ④ 有明确捐赠或开发 TapeOut 工具 / 游戏的记录

无效

  • 仅点赞 / 纯转发 / 关注
  • 仅单词提及；空泛回复（如只有“不错”）
  • 与 TapeOut 无关的其他项目内容
  • 提交时间高度集中的批量投票批次（按基金会数据库口径）

间接讨论可计入，但要判断是否真正参与了社区讨论。

标准按基金会给定的口径执行；我们不对任何账号作“有组织行为”的判断，只看内容是否满足标准5 / 13
